# phage-selective-early-prediction

Simulation-trained Transformer ensembles for early phage–bacteria outcome prediction. A frozen selective policy with exact binomial error bounds is tested on an untouched lockbox and certified on a new cohort, then stress-tested under assay, kinetic and latent-period mechanism shift. This is a simulation-based methodological study.

## Overview

This repository contains the complete code, models, and results for the manuscript: *"Risk-Controlled Selective Early Prediction of Phage-Bacteria Dynamics with Simulation-Trained Transformer Ensembles under Assay and Mechanism Shift: A Simulation Study"*.

The framework uses a vectorized two-phage chemostat simulator to generate synthetic trajectories. Transformer ensembles are trained on sparse, noisy, left-censored observations to predict 24-hour outcomes. A frozen three-stage selective policy (failure/persistence at 2 h, rebound at 4 or 6 h, or abstain) is evaluated using exact one-sided binomial upper bounds for each action.

## Repository Structure

- **`notebook-phase-selective-early-prediction.ipynb`**: Main Jupyter notebook containing the training, calibration, threshold selection, and evaluation pipeline.
- **`requirements.txt`**: Python package dependencies.
- **`LICENSE`**: MIT License.
- **`software/`**: Core simulation and solver code.
  - `cocktail_core.py`: Vectorized PyTorch implementation of the two-phage chemostat model (fixed delay).
  - `cocktail_chain.py`: Erlang-chain solver used for the distributed latent-period mechanism shift.
  - `manifest.json`: Metadata and run fingerprints for reproducibility.
- **`results/`**: All outputs generated by the pipeline.
  - `certification.json`: Certification cohort results.
  - `config.json`: Configuration used for the final run.
  - `environment.json`: Software and hardware environment details.
  - `policy.json`: The frozen policy thresholds and settings.
  - `figures/`: All generated figures (including those not in the Supplementary Materials).
  - `models/`: Trained model checkpoints.
  - `tables/`: All generated tables.
